# Beyond Text

Presentation materials for **Beyond Text: Building a 3D terminal emulator in Rust**.

## Presenting

Install [presenterm](https://github.com/mfontanini/presenterm) and [WezTerm](https://wezfurlong.org/wezterm/), then run:

```bash
./present.sh
```

To launch presenterm directly:

```bash
presenterm presentation.md -X -c config/presenterm.yml -p
```

Some slides contain runnable command snippets. Update their paths and commands for the machine used to present.
